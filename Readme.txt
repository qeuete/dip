 Для локального запуска веб-приложения запустите файл "WebAppSportFoodStore.exe".
 1. откройте приложение Docker Desktop  
 2. корнеевую папку проекта MealExpress (где находится файл "docker-compose.yml") откройте в терминале. 
 3. введите команду "docker-compose up --build"
 4. подождите, пока соберутся все контейнеры.
 5. вставьте ссылку в URL строку браузера: http://localhost/
 6. после открытия веб-приложения, зарегистрируйтесь. первый зарегистрированный пользователь является Администратором.
 7. выйдите из системы и зарегистрируйте второго пользователя.
 8. выйдите из системы и авторизуйтесь как Администратор. зайдите на страницу "Управление Пользователями", наведите мышкой на ФИО пользователя (созданного в пункте 7) в списке пользователей и назначьте ему роль "Менеджер".
 9. Выйдите из системы и зарегистрируйте третьего пользователя.
 10. Выйдите из системы и авторизуйтесь как . зайдите на страницу "Управление Пользователями", наведите мышкой на ФИО пользователя (созданного в пункте 9) в списке пользователей и назначьте ему роль "Курьер".
 11. Выйдите из системы и зарегистрируйтесь.
 12. Выйдите из системы. Теперь, все пользователи созданы. Ознакомьтесь с руководством пользователя для дальнейшего использования веб-приложения MealExpress.
